# PyVulnScan 🔍

A Python-based network vulnerability scanner that identifies open ports, detects services, and checks for known CVEs.

## Status
🚧 Under development

## Features (planned)
- Port scanning with multi-threading
- Service & version detection via banner grabbing
- CVE lookup via NVD API
- HTML report generation

## Installation

```bash
git clone https://github.com/yourusername/PyVulnScan.git
cd PyVulnScan
python -m venv venv
.\venv\Scripts\Activate.ps1  # Windows
pip install -r requirements.txt
```

## Disclaimer
This tool is for educational purposes and authorized security testing only. Do not use it on networks you don't own or have permission to test.
